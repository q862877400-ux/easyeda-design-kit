## 四、这条视频对我们的三个实际影响

1. **接入路径假设要改**：我们一直走 CLI（169 动作）。视频确认还有 MCP 与 API-RUN Gateway 两条；
   本机 **MCP 服务不存在**，Gateway 装了但没验证过 —— 以后写"可接入方式"时不能再笼统说"支持 MCP"。
2. **"文生原理图"有正面证据**：视频演示的"多图页组织、器件摆放、网络连接"与我们的 `sch compose` /
   `block-apply` 是同一条路；我们已经用它造出两块过验收的板。
3. **工程复核不能只靠 DRC**：视频把复核拆成"引脚/网络、启动复位时钟、扇出间距、器件归属"。
   我们的门禁只自动覆盖前者的机械部分与后三者；**功能性正确（时钟/复位时序）没有判据**，
   这一点应写进能力边界，而不是让门禁的绿灯暗示"整板电气都对"。
