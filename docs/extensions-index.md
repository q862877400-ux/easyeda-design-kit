# 75 个已装扩展：按「什么情况用什么」索引

> 这份表的目的只有一个：**别手搓**。遇到下面任何一种情况，先在这里找一行，再去调那个扩展。
> 所有扩展都已装、都已开「允许外部交互」。调用方式见 SKILL.md 的「两层」说明。
>
> 更新：2026-10-29。来源 = 扩展广场 API 全量 240 个里挑出并实际装上的 75 个。

## A. 开工 / 连接

| 情况 | 用这个 | 关键点 |
|---|---|---|
| 要程序化驱动 EDA（193 条命令） | **AI 指令引擎** | 端口 49720，需 `node bridge/command-proxy.mjs`，菜单「启动桥接」 |
| 要跑裸 `eda.*` JS | **Run API Gateway** | 端口 49620，`POST /execute {"code":"..."}`，返回 `{success,result}` |
| 要 CLI 风格类型化动作 | **EDA Agent Connector** | 端口 60832-60841，`easyeda.exe` 二进制，`--help` 有全量动作 |
| 让 DSH 本体直接进 EDA | **ai助手（deepseek-harness）** | 自然语言驱动原理图/PCB，支持上传数据手册 |
