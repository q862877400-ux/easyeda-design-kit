# 这套 kit 现在能做什么

> 这一页是**结论**，不是介绍。数字来自门禁实测（`acceptance/run.ps1 -Static` 与 `selftest.ps1`）。
> 最后更新：2026-11-01（第 70 轮）。边界 82 条，其中 open 29 条（resolved 40 / accepted 13）。

## 能做

| 能力 | 证据（可自己复跑） |
|---|---|
| **从一句需求到一块能验收的板**（5 种电路类型） | 五块板端到端跑通：LED / LDO / P-MOS / ESP32 自动下载 / USB-C 输入前端。现口径每块 **18 PASS / 1 FAIL / 0 BLOCKED**，唯一 FAIL 是 DRC 非 0 |
| **把别人画的 `.epro2` 导进来** | 已导入 `ESP32S3_USB`：**8 页原理图 + PCB2**（45 器件 / 29 网）。GUI 路径：导入专业版 → 页面模态 → 原生框选文件 → 二次确认（GAP-032） |
| **A4 上塞大块**（6 件以上、多脚连接器） | `playbooks/big-block-fit`（14 步）；`220/3` 能让 USB-C 六件块进 A4，判据非单调，配方与反例都记在 playbook 里 |
| **37 步可执行配方** | 4 个 playbook；每步的命令、**flag、取值类型**都经门禁校验（`37 步 / 27 flag / 37 步类型校验`） |
| **外部布线器接入** | DSN → `pcb_autorouter` → SES → 导入；自造板实测 **29/29 连通**，USB-C 六件板 359 ms |
| **门禁自己会抓自己的错** | 22 阶段 / 46 条断言 / 16 个历史错误对照。本会话多次**门禁先于我发现**真实回归，逐条记在 `capability-boundary.md` 的 GAP-067/068/069/070/072/073/074/075（例：playbook 编造 flag 曾判 PASS、能力计数把运行产物当能力、证据扫描只盯 4 份文档） |

## 不能做（附原因，不含"努力一下也许能"）

| 不能做 | 原因（已定性，不再重试） |
|---|---|
| **DRC 0** | 两次**独立重建**得到**逐条相同**的 3 条违规（Slot Region 11.7/11.8、Pad-to-Track 5.1/6、Netlist Error）⇒ 不是摆放问题；修它需要 slot/pad 级 clearance 参数、走线级编辑、或 GUI 手工改线——**三者当前皆不可得**（GAP-058） |
| **修单条走线的几何** | CLI **没有走线级编辑命令**；PCB 备份导出在本项目上失败 ⇒ 改不了也回不去（GAP-053） |
| **焊盘级诊断** | 没有焊盘级查询命令；外部板 DSN 导出失败的首要嫌疑正是那个畸形焊盘（GAP-059/063/065） |
| **决策表当手册用** | 111 行里只有 **18 行**在当前机器上可执行；**73 个被点名的工具中有 60 个本机未装**——它是目录，不是手册（GAP-071 前的收紧） |
| **全自动 GUI** | 三条前置缺一不可：浏览器+扩展 connected、会话每 ≤4 分钟保活、daemon 在线。其中"打开浏览器"是**人的动作**（GAP-064） |
| **换模型验证** | SC-004 的模型维度**未验证**——需要第二个模型入口（业主提供） |

## 29 条 open 边界 → 7 个根因

`docs/boundary-root-causes.md` 有完整表。一句话版：

- **R1 走线/过孔资源与布线器能力**（7 条）
- **R2 DRC 几何闭环缺失**（5 条）
- **R3 组包络与 A4 排版**（6 条）
- **R4 GUI 自动化前置与环境回收**（5 条）
- **R5 外部板 DSN/绑定**（2 条）
- **R6 CLI 只读查询缺口**（2 条）→ **已闭合**（能力以类型化动作存在，缺的只是 CLI 子命令）
- **R7 扩展"装上≠能用"**（1 条）

**R1/R2/R3/R5 共 20 条卡在同两件能力上**：缺走线级编辑、缺焊盘级诊断。
**补上其中的走线级编辑，一次解开四个根因**——这是当前最值得投入的一件事。

