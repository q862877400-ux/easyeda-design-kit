## 二、只从功能描述得到的需求（第 2 步）

从 README 抽出的功能要点：

1. 通过 CH224A 与 PD/QC 充电器协商，输出 **5V–28V**（PD 模式），并能读最大电流。
2. 控制方式两种：**GPIO/电阻档位选择** 或 **I²C 动态设定**（`setVoltage(0..7)`）。
3. 引出 **I²C（SDA/SCL）**、**PG（power good，开漏低有效）**。
4. 为 **5V 逻辑 MCU** 使用时，需走板上的 5V 电平侧引脚。
5. 提供 **R2 位（1 kΩ）模拟 e-marker**，装了可谈 5A，默认不装。
6. 形态：**23 × 15.24 mm**、面包板友好、单页原理图。

数据手册（第 9–10 页参考电路）给出的硬约束：

- CH224A = ESSOP10；pin0 = GND/EPAD、pin1 = VHV（**外接 1 µF**）、pin2 = CFG2/SCL、pin3 = CFG3/SDA、pin9 = CFG1、pin10 = PG、pin6/7 = CC2/CC1、pin4/5 = DP/DM、pin8 = VBUS。
- 单电阻配置：**CFG1 经 Rset 到 GND** 选档；此时 CFG2/CFG3 可作 I²C。
- I/O 电平配置：**CFG1 经 100 kΩ 接 VHV**（不带 MCU 时固定高阶电压）。
- MCU 控制：CFG1 接 GPIO，3.3V 逻辑串 **0 Ω**、5V 逻辑串 **2 kΩ**。

## 三、我自己的设计草案（第 3 步：只到"设计与选型"层面）

| 位号 | 器件 | 作用 |
|---|---|---|
| J1 | USB-C 16P 母座 | 输入 |
| U1 | CH224A（ESSOP10） | PD/QC 协商 |
| C1 | 1 µF | VHV 去耦（手册硬要求） |
| C2 | 10 µF | VBUS 储能（**我的加项，手册未要求**） |
| C3 | 100 nF | VBUS 高频 |
| R1 | 100 kΩ | CFG1 → VHV（I/O 电平配置） |
| R2 | 1 kΩ（DNP） | e-marker 模拟位 |
| R3/R4 | 4.7 kΩ ×2 | I²C 上拉 |
| LED1 + R5 | 0603 LED + 1 kΩ | 电源指示 |
| J2 | 2×4 排针 | 引出 VBUS / GND / SDA / SCL / PG / 3V（由主控供给） |

**我当时的判断**：这是"够用"的设计，约 12 个器件，能覆盖 README 的三条特性。

## 四、它的真实设计（第 4 步：读完它的原理图后）

单页 1/1，标题 `CH224A TRIGGER BOARD` rev 1.0，作者 EasyEDA 绘制。共 6 个功能区：

| 区 | 元件 | 作用 |
|---|---|---|
| USB TYPE C CONNECTOR | U3 = `MC-TYPE-C-16P-01A` | A1B12→GND、A4B9→VBUS、A5→CC1、B5→CC2、A6→D+、A7→D−、A8/B8→SBU1/SBU2（**SBU 悬空**）、外壳→GND |
| CH224A BLOCK | U1 + C1 1 µF | VHV←VBUS；CC1/CC2、DP/DM、VBUS 直连；**PG 引出**；CFG1 经 **100 kΩ 接 VHV** |
| 5A eMarker | R2 1 kΩ | **GND ↔ CC2**，注明 `NORMALLY UNPOPULATED` |
| **5V↔3V 电平转换** | **Q1/Q2 = BSS138**，R9/R8 4.7 kΩ 上拉到 3V，R4/R3 4.7 kΩ 上拉到 3V | I²C 在 **IO3_SDA / IO2_SCL（5V 侧）** 与 **…_3V（3V 侧）** 之间双向电平转换 |
| 12 PIN 排针 ×2 | U2 / U4 = `HBP-H3-25416PB2G0P` | 引出 3V、5V、IO3_SDA_3V、IO2_SCL、IO3_SDA、IO10、IO11、IO1、A4、GND、VBUS |
| **电压选择跳线** | R7 120 k / R1 24 k / R8 0.8 k | 三只 Rset 焊位，**不接 MCU 也能选档** |
| POWER LED | R5 5.6 k + LED1 0603 | VBUS → LED → GND |

## 五、对比结论（对我方不利的部分必须放在最前）

### 5.1 我的设计**有两处功能性缺失**，不是风格差异

| # | 缺失 | 后果 |
|---|---|---|
| **1** | **完全没有 I²C 电平转换**（它用 2× BSS138 + 4 只 4.7 kΩ 做双向转换） | 我的草案假设主控能直接对接 CH224A 的 5V I²C。**3.3V 主控接上去要么不通信、要么灌电流**——这是我设计上的**实质错误**，不是简化。 |
| **2** | **没有"无 MCU 也能用"的档位跳线**（它给了 5V/10V/20V 三个 Rset 焊位） | 我的 R1→VHV 只固定一种电平配置；**板子离开 MCU 就只剩一个默认档**，功能面窄一档。 |

### 5.2 我猜对的部分

- **1 µF 接 VHV**：与手册一致，两边都有。
- **CFG1 经 100 kΩ 接 VHV**：与它一致（I/O 电平配置路线）。
- **e-marker 位 DNP**：两边都是"留焊位不装"；它的接法是 **GND ↔ CC2**，我当时只能写"从 CC 到 GND"——**CC1 还是 CC2 这一细节我是猜的**，猜不中就会变成另一个网络。
- **SBU 悬空**：与我一致。
- **USB-C 16P + 外壳接地**：一致。

### 5.3 我比它多的一项（也要说）

- 我加了 **C2 10 µF VBUS 储能**；它的 Gerber/原理图里**只有 1 µF 接在 VHV**，VBUS 侧没有大电容。
  这在"接长线/热插拔/瞬态"时是短板——但这一条属**设计取舍**，不是它的错误；反过来也说明**我的"多一颗电容"并不能抵消上面两处功能缺失**。

### 5.4 Gerber 级定量（它给的原始数据，实测解析）

| 指标 | 实测值 |
|---|---|
| 板尺寸 | **23.00 × 15.24 mm**（从 `Gerber_BoardOutlineLayer.GKO` 解析，单位 µm：X 0–2299995、Y −1523997–45） |
| 铜层 | **2 层**（GTL / GBL） |
| 顶层 | D01 画线 **1970** 次、D03 闪焊盘 **85** 次 |
| 底层 | D01 画线 **995** 次、D03 闪焊盘 **52** 次 |
| PTH 孔 | **40** 个（0.306 / 0.310 / 0.600 / 1.101 mm） |
| NPTH 孔 | **2** 个（0.650 mm） |
| 过孔 | **24** 个（0.306 / 0.310 mm） |

**对比我方同类板**（`sc001-usbc-blk`，六件 USB-C 块）：板框 715×1388 mil ≈ **18.2 × 35.3 mm**，也就是**面积约为它的 1.8 倍**，而器件数只有 6 个。它的 23×15.24 mm 里塞了约 20 个器件 + 24 过孔。

## 七、这次实验真正的结论

1. **"从功能反推电路"这一步，我确实会漏东西**，而且漏的是**电气上会出问题的**东西（电平转换），不是审美问题。
   这条正好印证了此前预判：**画板是强项，选型+拓扑是短板**。
2. 数据手册能救回一部分（1 µF、100 kΩ、CFG 三种接法我都用对了），**但"主控是 3.3V 还是 5V"这种需求侧信息，
   以及"没有主控也要能用"这种产品侧考虑，我漏了**。
3. 因此可行的工作方式不是"我说一句话它自己画"，而是：**我出草案 → 你或我按数据手册逐条核对（尤其是电平、上下拉、去耦）→ 再画**。
   这套 kit 的门禁能保证"画得对、画得完、不假绿"，但**它不保证"电路本身是对的"**。
